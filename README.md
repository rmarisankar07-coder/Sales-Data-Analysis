## Dataset Columns
The output CSV contains the following uppercase columns:
*   ORDER_ID: Unique identifier for the transaction.
*   ORDER_DATE: Date of the transaction.
*   PRODUCT_NAME: Name of the item sold.
*   CATEGORY: Product category (e.g., ELECTRONICS, CLOTHING).
*   QUANTITY: Number of units sold.
*   UNIT_PRICE: Price per single unit.
*   TOTAL_AMOUNT: Total revenue (QUANTITY * UNIT_PRICE).
